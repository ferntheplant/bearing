# Triage promotes into build tickets

Triage promotes into build tickets because the cheapest verdict that fits
([Two ticket types, discriminated by how they close (ADR 0007)](./0007-two-ticket-types-discriminated-by-how-they-close.md))
is work that can close as a commit. A design ticket is a mapping exercise: the question must be read, placed on
a map, and answered somewhere durable, so creating one remains a deliberate act outside triage.
