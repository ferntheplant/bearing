# Check ranking against a tracker with real spread

Ranking is transitive gate count, plus fog cleared for design tickets, and nothing else. It has never been run
against a tracker with enough spread to produce an order anyone could agree or disagree with.

**The first observation is already in.** The five tickets this tracker opened with have no blockers between
them, and each design ticket clears exactly one patch — so every gate count is zero, every fog count is one, and
`bearing next` would have no order to show at all. That is not a defect in the ranking; it is what a map looks
like before anything on it has been walked. But it is precisely the moment someone most wants to be told what to
do first, and the ranking has nothing to say. Worth knowing whether that persists.

Two things to look at once there is spread: whether gate count plus fog produces an order a person actually
agrees with, and what the tiebreaker should be when it does not — the arbitrary order that ships in the meantime
is a placeholder, not a decision.

Nobody has committed to it, and it cannot be worked until a tracker with real spread exists.
